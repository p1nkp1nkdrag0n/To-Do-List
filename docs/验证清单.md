# 比赛前验证清单

按顺序做一遍，大约 20 分钟。每一步都写了「预期结果」，对不上就把截图发我。

---

## 一、干净安装（5 分钟）

```
1. 把 release\ToDoList.exe 复制到桌面（或任意空文件夹）
2. 双击
3. 首次会解压，约 1 分钟
4. 浏览器自动打开
```

**预期**：

- [ ] 先出现「开始之前，请先看这 5 条」→ 点「我知道了」
- [ ] 自动弹出「演示教程 · 从注册到甘特图」→ 看完或点「跳过教程」
- [ ] 进入「欢迎使用 · 创建管理员」
- [ ] 填：显示名称 `邱业恒`、用户名 `qiuyeheng`、密码 ≥8 位
- [ ] 创建后进入「创建第一个项目」，开始分步引导

---

## 二、建项目与引导（3 分钟）

```
1. 点「开始创建」→ 项目名填「比赛项目」→ 创建
2. 依次点「下一步」，走完 7 步引导
```

**预期**：

- [ ] 第 4 步「调整时间视图」**不卡住**，自动切到甘特图并高亮工具栏
- [ ] 可随时用左侧「会议 / 甘特图」切换，**不会被强行拉回**

---

## 三、配置思必驰（3 分钟）

```
1. 会议 → 右上「手动」→「AI 设置」
2. 滚到底部「语音转写（思必驰）」→ 切到「自己填写」
3. productId 填：279636026
4. apiKey 填：你申请的那把
5. 点「保存」→ 点「测试连接」
```

**预期**：

- [ ] 保存成功，显示 `Key ****xxxx`
- [ ] 测试连接返回「鉴权通过。额度是否充足要等真正转写时才知道。」
- [ ] 点「复制分享配置」→ 剪贴板里得到 `asr://279636026:...`
- [ ] 点「二维码」→ 出现二维码图片

---

## 四、上传录音（3 分钟）

```
1. 会议 →「上传会议录音」
2. 点「选择音频文件」→ 选 release\演示案例\演示会议-单人版-邱业恒.mp3
3. 热词框可点「从项目成员填入」，或留空
4. 点「开始转写」
```

**预期**：

- [ ] 顶部出现进度条：`上传第 1/1 片` → `等待服务端排队` → `服务端进度 x%`
- [ ] 约 10–30 秒后，纪要框自动填入文字
- [ ] 文字里出现「**邱业恒**」而不是「秋叶恒」
- [ ] 点「开始处理」→ 抽出 4 条任务，负责人都是邱业恒
- [ ] 处理完自动跳甘特图

**如果没配 Key 就点开始转写**：

- [ ] 应显示红字「还没有配置思必驰的 productId / apiKey」，并自动打开设置面板

---

## 五、Key 存放位置（2 分钟）

```
1. 关闭程序窗口
2. 打开资源管理器，进入：
   exe 所在目录\ToDoList-app\ToDoList-data\data\
3. 应该能看到 asr\ 和 llm\ 文件夹
4. 再看：ToDoList-app\app\data\ 应该没有这些文件夹
```

**预期**：

- [ ] Key 在 `ToDoList-data\data\asr\`（数据目录）
- [ ] 程序目录 `app\data\` 里没有 Key
- [ ] 重新双击 exe → 不需要重新填 Key，直接能用

---

## 六、队友流程（可选，同一台电脑就能测，5 分钟）

```
1. 用主账号：侧栏「注册邀请码」→ 生成 → 复制
2. 退出登录 → 注册第二个账号（显示名称「张工」），粘贴注册邀请码
3. 用主账号「邀请项目成员」生成 6 位项目码 → 张工登录后兑换
4. 张工：会议 → 手动 → AI 设置 → 语音转写 →「导入团队配置」
5. 粘贴主账号的 `asr://...` → 导入 → 测试连接
```

**预期**：

- [ ] 提示「已导入 productId 279636026，Key ****xxxx」
- [ ] 测试连接返回「鉴权通过」

---

## 七、异常情况确认（1 分钟）

| 操作 | 预期 |
|---|---|
| 上传超过 200MB 的文件 | 提示「文件超过 200MB…」 |
| 不选文件直接点开始转写 | 提示「请先选择音频文件…」 |
| 思必驰 Key 填错 | 测试连接报错，带平台原因 |

---

## 出问题怎么办

1. 看黑窗口里的报错
2. 页面上的红字提示
3. 记录：哪一步 + 截图 + 时间
4. 发我

**本地演示环境**（`npm run demo`）和 exe 是同一套代码，也可以先在那里快速试。
